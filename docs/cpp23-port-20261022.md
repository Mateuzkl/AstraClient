## Política e escopo

C++23 obrigatório em CMake e nas seis configurações de vc23. GCC/Clang usam
`-std=c++23`; MSVC 19.43+ usa `/std:c++23preview` (compilador local: 19.51).
Não foi usado c++latest, desativação global de char8_t nem fallback para C++17/20.
Flags das bibliotecas C/vendor não foram trocadas indiscriminadamente.

O port mantém os ajustes de alinhamento de Item/packed_any/packed_storage,
conversão explícita de UTF-8 para APIs C e retorno de string vazia no TinyXML.
São correções de compatibilidade/UB, não mudanças de protocolo de rede.
Não há promessa de ganho de FPS/RAM só por mudar o padrão da linguagem.

Android legado continua explicitamente bloqueado: projeto Clang_5_0 sem SDK/NDK
compatível. macOS, Win32 completo e dispositivo Android não foram certificados.
Não executar os runners live com credenciais reais sem uma escolha explícita.
